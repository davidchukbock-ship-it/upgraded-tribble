Ресурсы

Ресурсы

Руководства, калькуляторы и инструменты для работодателей, которые только начинают международный найм.

Знания

  • Глоссарий международного найма
  • Блог

    В блоге появятся практические статьи для работодателей, которые только начинают международный найм: как работают разрешения, что спросить у исполнителя, как планировать сезон.

  • Обзоры провайдеров

    Выбрать исполнителя по подбору трудно, когда не видно его работы.

Инструменты для HR

  • Калькулятор зарплаты

    Калькулятор зарплаты — инструмент, который показывает типичную оплату роли в выбранной стране.

  • Калькулятор адаптации

    Калькулятор адаптации — инструмент, который оценивает время и стоимость вывода нового работника на работу.

  • Калькулятор юрлица

    Калькулятор юрлица — инструмент, который сравнивает стоимость открытия собственной компании за рубежом с другими вариантами.

  • Калькулятор выходного пособия

    Калькулятор выходного пособия — инструмент, который оценивает, что работодатель может быть должен при окончании работы, по странам.

  • Проверка статуса занятости

    Проверка статуса занятости — инструмент, который помогает понять, подрядчик ли человек на самом деле или он должен быть сотрудником.

Финансовые инструменты

  • Глобальный калькулятор зарплаты

    Глобальный калькулятор зарплаты — инструмент, который превращает оклад до налогов в реальные расходы работодателя в выбранной стране.

  • Генератор расчётных листков

    Генератор расчётных листков — инструмент, который создаёт понятный расчётный листок по введённым вами данным.

  • Генератор 1099

    Генератор 1099 — инструмент, который готовит американскую форму 1099, в которой отражаются выплаты подрядчикам.

  • Генератор W-2

    Генератор W-2 — инструмент, который готовит американскую форму W-2 с годовой оплатой и налогами сотрудника.

Руководства по странам

  • Руководства по странам

    Руководство по стране объясняет для одной страны основное, что должен знать работодатель: виды занятости, сроки уведомления, налоги, праздничные дни и разрешения, которые нужны работникам.
